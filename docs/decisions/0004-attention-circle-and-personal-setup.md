# 0004 — Attention circle and personal setup

Date: 2026-09-18. Builds on [Draft 03](0003-personal-awareness-and-faster-film.md).

## User direction

Manish described a seated person at the center of a circle that gradually fills
with daily demands. The person should look at each incoming item and become
increasingly overwhelmed: routine Slack questions, 150 unread emails, ten pings,
and three meeting invites including two during their night. AI Peer should help
with routine work so the person can focus where they want and are needed most.

He also requested a visible, simple creation sequence: Create my AI Peer →
OneAirbnb profile → team/projects → Sourcegraph/GitHub work and owned services →
Slack/Zoom access → ready → the established demonstration.

## Decision

Draft 04 replaces the first 40 seconds of Draft 03 with a 53-second opening and
setup. It retains the later personal brief, conversations and return. The final
film is 179.5 seconds (2:59.5).

The same drawn person and ring continue through overload and relief. Eyes, head,
brows, mouth, shoulders and a hand gesture react to each source. The pressure
cards visibly travel toward the Peer, the person relaxes, and one focus task
remains in front of them. This gives the reveal a causal payoff.

Setup makes the relationship explicit rather than only presenting connector
logos: an illustrative OneAirbnb profile yields Manish → Payments Platform →
Chargebacks; Sourcegraph reveals event-mapper.ts and a reconciliation service;
GitHub adds recent changes and open checks; selected Slack and delegated Zoom
access follow. Approved mail/events and the ask-before-commitment boundary remain
visible. The later personal brief uses these same context details.

## Boundaries and production

The person is an original fictional vector illustration, not a likeness. All
profile facts, source screens and code are authored concept examples. No internal
OneAirbnb site was accessed and no connector or live product was implemented.
The user supplied OneAirbnb as the desired profile source; its API and real UI
have not been verified. Every source window says illustrative setup.

All thirteen new voice clips run at natural speed. Twenty-two selected Draft 03
performances are reused exactly, preserving the improved conversations. Original
124 BPM music gains spatial attention cues and a brief pre-reveal intake. Earlier
drafts and the original idea remain preserved.

Independent review corrected the early inbox expression, panel overflow and the
mapping-code example. See [storyboard](../video/draft-04-storyboard.md) and
[verification](../video/draft-04-verification.md).
