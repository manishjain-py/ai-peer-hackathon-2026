A worker reports a review or a limit in a line, and the line reads as closed. Read the reviewer's own note and count what it reaches
before ruling. Two cases in one night (Teacher Feedback QA, 2026-11-04): a fold "gave the reviewer the Hindi", but the note also said the
verdict did not bind those words, and the apply read them unchecked; a limit marked "goes in as a parked entry" turned out to stop every
fix on 23% of live cards, and became the proof's most useful finding.

**Why:** a summary carries the writer's frame, and a parked line hides the size of what it parks.

**How to apply:** before ruling, open the source (the note, the code line) and count the live rows it touches. A few minutes, read-only.
