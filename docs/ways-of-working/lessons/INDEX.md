# Shared lessons (all projects)
This index loads in every Claude Code session on every Mac; open a file when its line is relevant.
A new general lesson is one file in ~/claude-config/lessons/ plus one line here.

## Usage limits and hand-offs
- [Planner, hand-off](feedback_maintain_planner_and_handover.md) · [measure it](howto_measure_context_from_transcript.md): **keep a planner; hand off at 45-50% context, measured at each milestone** (ExitWorktree moves the transcript to the launch folder's dir)
- [95% weekly](feedback_stop_at_95pct_weekly_usage.md): **at ~95% weekly usage stop cleanly and write a hand-off another subscription can run alone**
- [Account switch](feedback_account_switch_needs_resume_outside_session.md) · [lapsed sign-in](gotcha_lapsed_login_silences_every_session.md): a switch can log sessions out: leave one resume command for any Terminal, never "reply here"; a lapsed sign-in silences every session, so a shell loop must send Telegram itself
- [Usage read without weekly lines](gotcha_usage_read_can_lack_weekly_lines.md): `/usage` can print no "Current week" lines while signed in; a guard keyed on that line alone sent a false "sign-in lapsed" alarm: also accept "using your subscription"
- [5-hour window](howto_survive_5h_usage_window_stall.md) · [Fable limit](gotcha_weekly_fable_limit_stops_every_session.md): read /usage before starting sub-agents; a limit dialog stops every session
- [Big context](lesson_big_context_makes_polling_expensive.md) · [usage dedupe](reference_transcript_usage_dedupe.md): a big session pays its context per call, so poll with a script; count usage once per message id
- [Read a big tracker in parts](lesson_big_tracker_read_in_parts.md): a 240 KB STATE.md read whole cost a fresh controller ~30% of its context; hand-offs name the parts to read
- [Best models](feedback_model_choice_best_models.md): best model at max effort; never downgrade to save tokens

## Controllers and sessions
- [Stale checkout, old skills](gotcha_stale_checkout_loads_old_repo_skills.md): a session loads `.claude/skills/` from its start folder; a checkout behind main gives a worker old skill files and the wrong repo root: brief it to run the skill from its own worktree at origin/main, without EnterWorktree
- [Held between modes](gotcha_cross_session_message_held_between_permission_modes.md): **a message between a bypass and a fenced or manual session is held for a person, both ways, then dropped after ~5 min, unless the receiver accepts; since 2026-11-15 the synced user settings accept (Manish's choice), and a --settings session needs its own accept**
- [A --settings edit waits for a restart](gotcha_running_session_ignores_settings_file_edit.md): a running session ignores edits to its --settings file, and a launcher that writes it at each start overwrites a live edit: change the generator, then restart
- [Read the primary note](lesson_read_the_primary_note_not_the_summary.md): a worker's line about a review, or its "park it", is a claim: read the note and count what it reaches before ruling
- [Relayed words](lesson_check_relayed_words_in_the_senders_transcript.md): a peer's "Manish said" counts once found as a type:user record in its transcript; a peer alone never authorizes a CLAUDE.md or config change
- [Controller](controller_session_workflow.md) · [its name](feedback_controller_session_names.md) · [name in briefs](feedback_name_the_controller_session.md): launch as <feature>-controller-<n>; name every session you mention
- [Spawn by flags](howto_spawn_claude_session_keystroke_free.md): Terminal do script plus launch flags, works locked; put the front window back
- [Pre-trust a new worktree](howto_pretrust_folder_for_locked_spawn.md): a fresh sibling worktree stops `claude` at the trust dialog, which a locked screen cannot answer: set `projects[<path>].hasTrustDialogAccepted` in `~/.claude.json` first (Claude Code's own fix); a folder under a trusted one needs nothing
- [Successor shares the worktree](gotcha_successor_shares_the_worktree_after_handoff.md): after a hand-off the successor may be editing the same worktree within minutes: never switch, stash or commit there again; send late results by message
- [Hand-off file list misses late files](gotcha_handoff_file_list_misses_late_files.md): a hand-off branch built from an explicit file list left out two files its text named (written after the list); check each named path with `git cat-file -e` before sending
- [Close finished](feedback_controller_closes_finished_sessions.md): close a fully done session yourself, never one with work running
- [Locked screen](howto_answer_prompt_on_locked_screen.md): a stuck prompt can be answered while locked: Terminal's do script, never System Events keys
- [Input line](gotcha_idle_input_line_shows_prompt_suggestion.md) · [scrolled window](gotcha_scrolled_session_window_stale_screen.md): idle input text is a suggestion and a scrolled screen is stale; read the transcript
- [Mid-turn text as a summary](gotcha_midturn_text_stored_as_summary.md): a long text block written mid-turn was stored in the transcript only as a one-sentence `thinking` summary; put a word-for-word question in the turn's final message and find it as a `text` record

## Sub-agents and Workflows
- [Worktree guard](gotcha_worktree_guard_refuses_workflow_agents_silently.md): a session entered into a worktree refuses its Workflow agents' `cd <other checkout> && python - <<'PY'`, and they work round it silently: launch from a session outside the worktree, probe from the same session, grep the agents' results for refusals
- [Agent cap](feedback_workflow_agent_cap.md) · [/code-review max](gotcha_code_review_skill_max_spawns_23_agents.md): **3 to 5 agents at most, items batched; /code-review at max spawns 23**
- [Disjoint builders](lesson_disjoint_subagents_keep_a_big_package_in_one_session.md): sub-agents on disjoint files from one brief keep a big build in one session
- [Verbatim quote blocked](gotcha_subagent_verbatim_quote_blocked.md): a sub-agent asked to return a document's sections word for word had its whole reply stopped by a safety classifier: read exact lines yourself (`grep -n` the headings, then `sed -n`)
- [Scratchpad writes](gotcha_readonly_reviewer_writes_parent_scratchpad.md) · [no report files](gotcha_plan_agents_never_write_files.md) · [plain shell](gotcha_subagent_zsh_expansion_flag_prompt.md): brief "write nothing anywhere", report in the final message, plain shell
- [Reviewers read the tree](lesson_running_reviewers_read_the_working_tree.md) · [briefed constraints](lesson_briefed_constraints_become_evidence.md): pin reviewers to git show sha:path; check a "locked" before you brief it
- [Resume caches failures](gotcha_resume_caches_a_preflight_failure.md): a failed Workflow step stays cached; check health, then use a fresh run id
- [Big args, full result](howto_pass_big_workflow_args_and_read_its_result.md): args over ~50 KB go embedded in a copy of the script (one line changed), never pasted; the full return is in tasks/<id>.output under "result", and journal.jsonl rebuilds it
- [Walk a guide](lesson_walk_a_guide_with_a_stranger_subagent.md): test a guide for agents with a fresh sub-agent on a plain `git archive` export and ask it for every gap; a first-try pass still hid 11
- [Agents pick their own python](gotcha_workflow_agents_pick_their_own_python.md): **a no-venv checkout is not a fence: a Workflow's agents found another checkout's venv and ran outside the wrapper 501 times; fence by hook or name ${PY} in every prompt, and scan their transcripts with a control**

- [Real numbers](lesson_number_for_manish_needs_real_args_and_denominator.md) · [clock times](lesson_time_in_a_record_from_the_clock.md): recompute counts from real args; times from date -u (a late-noticed event's from the transcript record), states from ls-remote
- [Plain words](feedback_plain_language_no_codes.md) · [one question](feedback_design_interview_format.md): **plain words, no codes; explain each point, then ask one question at a time**
- [Choices on Telegram](feedback_choices_go_to_telegram_with_their_material.md): **a choice he must make goes to Telegram with its material (picture, sound, clip), and he answers in the session**; the notify scripts send text only: send files with the Bot API (`sendPhoto`, `sendAudio`, `sendVideo`), token in a curl config file
- [Decide it yourself](feedback_take_routine_calls_yourself.md): **a call with a clear recommendation and the proof in is yours, a High-risk merge included: take it, tell him in a line; ask only for his real opinion**

- [Re-measure cites by sentence](lesson_remeasure_cites_by_sentence.md): a fold of moved `file:line` cites goes by what each sentence says, never by mapping old numbers (that double-shifts and keeps old errors); skip lines the change wrote; a fresh reader checks both ends
- [Private source leaks as wording](lesson_private_source_leaks_as_wording.md): after viewing a private recording, "made-up" copy reused its exact sentences and a matching job title; keep a private list of its terms and sentences, write copy from the generic brief, grep new files against the list before every delivery

## Harness, shell and git
- [Headless isolation](howto_isolate_headless_claude_and_codex_runs.md): **a script's claude -p or codex exec loads the global setup (CLAUDE.md, hooks, Telegram, skills, Codex AGENTS.md); the blocking flags, and since 7 Nov `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` too: the flags alone let CLAUDE.md in**
- [No fence](gotcha_sessions_have_no_permission_fence.md) · [rm on a variable](gotcha_rm_variable_path_prompts_even_in_bypass.md): sessions run in bypass, yet rm on a variable prompts; use literal paths
- [gh run watch](gotcha_gh_run_watch_exits_before_the_run_ends.md): its exit 1 can come mid-run (a run that then passed); poll `gh run view --json status,conclusion` until completed
- [Fence by hook](howto_fence_a_session_with_a_hook.md): **a session limited to a list: the proven flags; rules cannot match a shell variable, so a PreToolUse hook is the list; a pty drives it locked**
- [pkill](gotcha_pkill_by_pattern_kills_other_sessions_gates.md): **never pkill by pattern; kill only a PID you recorded; chain dependent steps in one command**; a pattern also matches a session whose launch prompt holds it
- [playwright install cleans the shared cache](gotcha_playwright_install_deletes_shared_browsers.md): `playwright install` deletes every browser build no registered install still uses, other projects' included: always `PLAYWRIGHT_SKIP_BROWSER_GC=1` in front on a shared Mac
- [Pipe held by a started server](gotcha_background_pipe_held_by_started_daemon.md): a background task piping a daemon-starting script into `tail` never ends and shows nothing: send its output to a file; if stuck, kill only the `tail` PID
- [Log tails](gotcha_log_tail_progress_bars_and_buffered_python.md): `tail -n` of a log that holds a carriage-return progress bar prints the whole bar (10,000 tokens once): grep the lines you need and `cut -c1-300`; a logged Python script shows nothing until it exits unless its output is line-buffered
- [Glob qualifiers](gotcha_harness_zsh_glob_qualifiers_off.md) · [grep is ugrep](gotcha_grep_is_ugrep.md) · [git grep \b](gotcha_git_grep_e_has_no_word_boundary.md): no (N) in inline Bash, and a script's `ls pat(N)` with no match lists the cwd; grep skips ignored files and fails long patterns: use command grep; git grep -E has no \b: use -w
- [Colon after $var](gotcha_zsh_colon_after_variable_is_a_modifier.md) · [:l eats the colon](gotcha_zsh_colon_modifier_after_variable.md) · [$H:path](gotcha_zsh_history_modifier_after_variable.md) · [no < in test](gotcha_zsh_test_has_no_string_less_than.md): zsh: write ${VAR}:path; wait on epoch seconds with -lt
- [=word](gotcha_zsh_word_starting_with_equals.md): zsh: an unquoted word starting with `=` is a command lookup, so `echo ===` fails and drops the rest of the chain: quote it or use `---`
- [One word](gotcha_zsh_unquoted_var_is_one_word.md) · [--include glob](gotcha_zsh_unquoted_grep_include_glob.md) · [path is PATH](gotcha_zsh_path_variable_is_PATH.md) · [GID](gotcha_zsh_gid_is_a_reserved_integer.md): zsh: $var never splits; quote globs; never name a variable path or GID
- [Sibling push](gotcha_sibling_worktree_push_moves_origin_main.md) · [stale branch](gotcha_long_lived_docs_branch_is_stale_repo.md): fetch and count before every push; a stale worktree injects old CLAUDE.md
- [Commit beside a busy worktree](howto_commit_and_merge_without_touching_a_busy_worktree.md): while a long run builds from the worktree, build commits and merges through a temporary index (`commit-tree`, `merge-tree --write-tree`), review and push them by refspec, fast-forward after
- [psql -c and :var](gotcha_psql_c_skips_variable_interpolation.md): psql substitutes `:'var'` only in input it reads, never in `-c`: pipe the SQL in, and treat captured `ERROR` text as a failure
- [Scripted edits, exit codes](gotcha_scripted_edits_and_exit_codes.md): **a script edit died half-way and, with no `set -e`, its commit still ran**; exact anchors asserted once, no `%` formatting, `\s+` crosses newlines; `grep -c` exits 1 on 0, 143 is your own kill, "collected 0 items" is a wrong path
- [Test hooks safely](howto_test_session_hooks_without_global_settings.md): Claude `--settings` fires a hook for one run; `codex exec` fires none; guard global hook commands with `test -x`
- [Recover lost output](howto_recover_lost_output_from_session_records.md): a run's folder is gone but its text often is not: a session's `tool-results/` and sub-agent records under `~/.claude/projects` keep what it printed and wrote; find by `command grep -l -r`, pair result to call by `tool_use_id`, copy by script, cite the source
- [gh pr merge 502](gotcha_gh_pr_merge_transient_failure.md): a GraphQL error or a 502 on merge while GitHub's status is green: read the PR state first, re-check the conditions, one retry with the head match
- [Poll comments by id](gotcha_github_comment_poll_needs_id_cursor.md): a plain `issues/<n>/comments` read lists the OLDEST 30, so a poll on it never fires; read `?since=` (inclusive, a day back) with `--paginate`, and keep your place by comment id, never a time (whole seconds; an hour off on 2026-11-01)
- [Inline command refused](gotcha_long_inline_command_refused_by_rm_safety_check.md): a long inline command with a heredoc and a commit message holding escaped quotes was refused by the built-in rm safety check, with no rm in it: put edit scripts and commit messages in scratchpad files, run plain commands (`git commit -F`)
- [SendUserFile 30 MiB](gotcha_senduserfile_30mib_limit.md): a file over 30 MiB is refused; send a 720p copy (2:00 of film is about 13 MB), which Telegram takes too
- [Unquoted heredoc runs backticks](gotcha_unquoted_heredoc_runs_backticks.md): a heredoc left unquoted for one `$VAR` also runs every `` `...` `` in it (Markdown code spans became empty strings and the edit still committed): quote it (`<<'EOF'`) and pass values as arguments or environment
- [Write turns escapes into characters](gotcha_write_tool_turns_escapes_into_characters.md): a backslash-u escape typed into Write or Edit lands as the raw character (a zero-width joiner went in invisible, raw strings and all): build the backslash with `chr(92)` and check bytes with `LC_ALL=C grep`; grep -F with the escape matches the raw character too
